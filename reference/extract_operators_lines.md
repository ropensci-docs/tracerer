# Extract the JSON lines out of a `.xml.state` with the unparsed BEAST2 MCMC operator acceptances file with the operators

Extract the JSON lines out of a `.xml.state` with the unparsed BEAST2
MCMC operator acceptances file with the operators

## Usage

``` r
extract_operators_lines(filename)
```

## Arguments

- filename:

  name of the BEAST2 .xml.state output file

## Value

the JSON lines of a `.xml.state` file with the unparsed BEAST2 MCMC
operator acceptances
